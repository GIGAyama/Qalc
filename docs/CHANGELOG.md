# 更新の記録

Qalc の変わったところです。

## 2026-11-15
- みんなであそぶで、メンバーのEXPや記録が残らないことがあったのを直しました
- 問題に正解すると、コインがもらえるようにしました
- 画面がひくいときや拡大したときに、テンキーが画面の外に切れて押せなかったのを直しました
- 答えを正解と同じ長さまで打つと、OKを押さなくても答え合わせをするようにしました
- 保存データがこわれていると、画面がまっ白になることがあったのを直しました
- 記録を保存できなかったときは、画面でそのことを知らせるようにしました
- 文章題や、問題の少ないドリル（九九の各段など）も、マスターできるようにしました
- アプリを開いたまま日がかわると、ミッションが進まなかったのを直しました
- 受けとりわすれたミッションのコインを、つぎの日にもらえるようにしました
- ひとりでは達成できないミッションや、遠すぎる目標のミッションが出ないようにしました
- 端末の言語を変えると、連続日数が1にもどっていたのを直しました
- サドンデスとタイムアタックで、終わったあとに打った答えまで記録に入っていたのを直しました
- 出る問題が、コースの前のほうの問題にかたよっていたのを直しました
- 3〜4年の分数で、約分した答えや「3/3」のような答えも正解にしました
- 小数の答えは「.5」のように打っても正解にしました
- どの端末でも、同じコースなら同じ問題が出るようにしました
- はじめからあるコースを直したあと、もとの問題にもどせるようにしました
- 問題文に「,」があるコースも、共有コードで正しく渡せるようにしました
- コースを取りこむと、同じ名前の前のコースが消えていたのを直しました
- テンキーで打てない答えの問題は、作るときに知らせるようにしました
- 自作コースの答えを全角で書いても、正解できるようにしました
- キーボードや読み上げでも、ショップ・コース管理・ダイアログを使えるようにしました
- 小さくて読みにくかった文字を大きくしました
- みんなであそぶで、人数が多いとリーダーの端末が重くなりやすかったのを軽くしました
- 新しいバージョンのお知らせが、ゲームの最中に出ないようにしました
- 正解したときの紙ふぶきが出ていなかったのを直しました
- プライバシーポリシーに、みんなであそぶの通信先などを書き足しました
