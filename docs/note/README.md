# note 用の紹介記事（納品物）

全国の小学校の先生に向けて、Qalc を note で紹介するための記事一式です。

| ファイル | 中身 |
|---|---|
| `qalc-note-article.md` | 本文。そのまま note に貼れる形（約7,900字） |
| `images/` | 本文で参照している画面のスクリーンショット（21点） |

---

## 貼るまえに直すところ（1か所）

タイトル1行目の **`#◯`（連載番号）** を、実際の番号に置きかえてください。
参考にした前回の Qalc の記事が「教室で使えるかもしれないもの作り #9」（2026年3月4日）だったところまでは
分かりましたが、その後の連載本数がこちらから確認できなかったため、伏せてあります。

---

## note に貼るときの手順

1. note で新規記事（テキスト）を作る
2. 1行目の `# 教室で使えるかもしれないもの作り #◯ …` を**タイトル欄に**入れる（本文には入れない）
3. 残りの本文を貼る。`##` の見出しは note がそのまま解釈し、目次も自動で作られます
4. 画像は貼りつけでは入らないので、`![...](images/xx.png)` の位置で `images/` の中の PNG を**手動でアップロード**する
5. 画像の**直後の1行がキャプション**です。note の画像キャプション欄に移してください（前回の記事と同じ形にしてあります）
6. いちばん下の「🏷 ハッシュタグ」の見出しごと本文から外して、タグをハッシュタグ欄に入れる
7. 見出し画像（サムネイル）には `images/01-home.png` か `images/14-boss-start.png` がおすすめ

本文には Markdown の表・太字・斜体を使っていません。貼るだけで崩れません。

## 文体について

いただいた執筆プロンプトと、前回の Qalc の記事（連載 #9）に合わせています。

- 見出しは 🏫 📱 ✨ 🛠️ 📖 📝 の並びを踏襲し、今回の目玉である「かんがえるどうぐ」と
  「みんなで挑むモード」に 💡 🤝 を足して2本ぶん追加しています
- 太字（`**`）、斜体、表、`→` `／` などの記号は使っていません
- 絵文字は見出しだけに使い、本文には入れていません
- 箇条書きは「使い方のガイド」の手順だけにとどめ、それ以外は文章で書いています
- デプロイ、ローカルストレージ、WebRTC といった言葉は使わず、日常の言葉に置きかえています
- 「導入のメリット」は前回と同じ「三つのいいことが期待できます」の型です
- 「児童」ではなく「子どもたち」で統一しています
- 締めは前回と同じ「一歩踏み出そうとする先生を、私はいつでも全力で応援しています。」です

前回の記事との地続きを大事にして、「以前紹介した Qalc を作り直しました」という書き出しにしています。
新規のアプリとして紹介したい場合は、🏫 はじめに の4段落目と5段落目、
🤝 の「前のものは番号が四けたでした」の段落、✨ の一つ目、🛠️ の書き出しを削ってください。

## スクリーンショットの撮りかた（撮り直すとき）

すべて実際にビルドしたアプリを実ブラウザ（Chromium）で操作して撮っています。合成・加工はしていません。

- 画面サイズは 390×940（`deviceScaleFactor: 2`）。ホームと入室許可だけ、1画面に収めるため縦を長くしています
- 「みんなであそぶ」の画面は、リーダー1台＋子ども5台（たろう・はなこ・けんた・ゆい・そうた）を
  同時に起動して、入室の許可からバトルの結果発表まで通して撮っています
- 作業環境からは `0.peerjs.com` に出られないため、撮影時だけシグナリングサーバをローカルに立て、
  `PEER_OPTIONS` の接続先を差しかえています（撮影後にもどしてあります）
- 同じ理由で、QRコードの下に出るURLを本番と同じ見た目にするため、撮影時だけ `gigayama.github.io` を
  ローカルに向けています

撮り直すときは、`tools/measure/` の実測ツールと同じ手順（`npm run build` → `node tools/measure/serve.mjs dist <port>`
→ Playwright で操作）で撮れます。
