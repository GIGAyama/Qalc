# note 用の紹介記事（納品物）

全国の小学校の先生に向けて、Qalc を SNS（note）で紹介するための記事一式です。

| ファイル | 中身 |
|---|---|
| `qalc-note-article.md` | **本文。そのまま note に貼れる形（約8,200字）** |
| `images/` | 本文で参照している画面のスクリーンショット（21点） |

---

## note に貼るときの手順

1. note で新規記事（テキスト）を作る
2. `qalc-note-article.md` の**1行目の `# ...` をタイトル欄に**入れる（本文には入れない）
3. 残りの本文を貼る。note のエディタは Markdown の見出し・箇条書き・引用・区切り線をそのまま解釈します
4. 画像は貼りつけでは入らないので、`![...](images/xx.png)` の位置で `images/` の中の PNG を**手動でアップロード**する
5. 画像の下の `*斜体*` の行を、note の**画像キャプション欄**に移す（本文からは消す）
6. 記事の末尾のハッシュタグを、note のハッシュタグ欄に入れる
7. 見出し画像（サムネイル）には `images/01-home.png` か `images/14-boss-start.png` がおすすめ

本文には Markdown の表を使っていません（note のエディタが表を解釈しないため、
表になりそうなところは最初から箇条書きと文章に開いてあります）。貼るだけで崩れません。

## スクリーンショットの撮りかた（撮り直すとき）

すべて **実際にビルドしたアプリを実ブラウザ（Chromium）で操作して**撮っています。合成・加工はしていません。

- 画面サイズ：390×940（`deviceScaleFactor: 2`）。ホームと入室許可だけ、1画面に収めるため縦を長くしています
- 「みんなであそぶ」の画面は、**リーダー1台＋児童5台（たろう・はなこ・けんた・ゆい・そうた）を同時に起動**して撮っています
- 作業環境からは `0.peerjs.com` に出られないため、撮影時だけ**シグナリングサーバをローカルに立て**、`PEER_OPTIONS` の接続先を差しかえています（撮影後にもどしてあります）
- 同じ理由で、QRコードの下に出るURLを本番と同じ見た目にするため、撮影時だけ `gigayama.github.io` をローカルに向けています

撮り直すときは、`tools/measure/` の実測ツールと同じ手順（`npm run build` → `node tools/measure/serve.mjs dist <port>` → Playwright で操作）で撮れます。

## 文体について

書き手（GIGA山）が、同じ小学校の先生に向けて自分の作ったアプリを紹介する、という立場で書いています。

- 教室でのできごとを実体験として書かない（作者自身の実践記録ではないため）
- 「〜できます」を並べず、なぜその作りにしたのかを添える
- 太字と記号は最小限（本文中の太字は5か所だけ）
- 効果の断定を避け、「〜と思います」「〜のつもりです」で止める
