# 計算ドリルの5分が、教室でいちばん盛り上がる時間になる ── 登録なし・無料の算数アプリ「Qalc（カルク）」の使い方

**URLを開くだけ。アカウント登録も、名簿の取りこみも、アプリのインストールもいりません。**
小学1〜6年の計算コースが**119コース・約12,800問**。そこに、クラス全員で遊べる協力バトルとチーム対戦がついています。

この記事では、はじめて使う先生に向けて

- 1人で使うときの手順（3ステップ）
- 「わからない子」を置いていかない仕組み（かんがえるどうぐ）
- クラス全員でやる遊びかた（ボスバトル／じんとりバトル）
- 個人情報・校内フィルタリングまわりの確認事項

を、実際の画面といっしょに紹介します。

▶ **アプリのURL** … https://gigayama.github.io/Qalc/

---

## 1. こんなこと、ありませんか

計算練習の時間になると、教室はだいたい3つに分かれます。

- **すぐ終わって手持ちぶさたになる子**
- **1問目で手が止まったまま、時間だけが過ぎる子**
- そして、**その両方を見ながら丸つけをしている先生**

プリントを刷る・配る・集める・丸をつける。この一連の作業だけで、休み時間はほぼ消えます。
かといってドリルアプリを入れようとすると、今度は「アカウントは？」「名簿は？」「個人情報は？」の壁が立ちはだかります。

**Qalcは、この2つを同時に外すために作られました。**
URLを開けば即スタート。児童の名前も、メールアドレスも、出席番号も、アプリは一切あつかいません。

---

## 2. Qalc（カルク）とは

ブラウザで動く、小学生向けの計算学習アプリです。

| | |
|---|---|
| **料金** | 無料（MITライセンスのオープンソース） |
| **登録** | 不要（アカウントなし・名簿登録なし） |
| **インストール** | 不要（ブラウザで開くだけ／ホーム画面に追加もできる） |
| **対象** | 小学1〜6年（119コース・約12,800問） |
| **端末** | Chromebook・iPad・Windows・スマートフォン |
| **記録の保存先** | **その端末の中だけ。外部への送信はありません** |

![Qalcのホーム画面](images/01-home.png)

*▲ ホーム画面。レベル・コイン・連続学習日数（🔥）・今日のミッション・がんばりグラフ・まなびのきろくが1画面にまとまっています*

児童がまず見るのは「Lv.4」「250コイン」「🔥1日」といったゲームの表示ですが、
先生が見るべきは画面のいちばん下、**「まなびのきろく（直近7日）」**です。
「何回あそんだか」「集中した時間」「**1回めで正解した割合**」、そして「もういちどやってみよう」に、
その子がつまずいた問題そのものが並びます。

## 3. まずは1人でやってみる（3ステップ）

### ステップ1：モードを選ぶ

ホームで **スコアアタック／タイムアタック／サドンデス** のどれかを押します。
迷ったら **スコアアタック** が無難です（制限時間内に何点とれるか。1〜10分で設定できます）。

| モード | 内容 | 向いている場面 |
|---|---|---|
| **スコアアタック** | 制限時間内にハイスコアをめざす | 帯タイム・すきま時間 |
| **タイムアタック** | 全20問をどれだけ早く終えられるか | 単元末の力だめし |
| **サドンデス** | 1問でもまちがえたら終了 | 確実さを求めたいとき |

### ステップ2：学年とドリルを選ぶ

学年タブでしぼりこみ、ドリルをタップして選びます。**複数選択もできます**（「九九の七の段だけ」も「2年ぜんぶ」も自由）。

![ドリル選択画面](images/02-drill-select.png)

*▲ 3年をえらんだところ。1コースあたり9問〜729問。制限時間はスライダーで1〜10分*

### ステップ3：スタート

あとは数字キーで答えて **OK** を押すだけ。**正解した瞬間に自動で次の問題へ進みます。**

![ゲーム画面](images/03-game.png)

*▲ 問題は大きく、キーは押しやすく。左下の電球が「かんがえるどうぐ」、右下のペンが手書きメモ*

連続正解すると「コンボ」がたまり、5コンボ以上で**フィーバーモード**に入って得点が伸びます。
「速く・正確に」がそのまま気持ちよさになるので、**声をかけなくても手が止まりません。**

## 4. このアプリの本体は「かんがえるどうぐ」です

ここがQalcのいちばんの特徴です。

ゲーム中に **電球のボタン** を押すと、**いま出ている問題に合った図** が下から出てきます。
どの図を出すかは、問題文と数の大きさから**自動で判定**されます。全部で25種類。

たとえば、こうなります。

### 3年「2けた×2けたのかけ算」→ ひっ算

![ひっ算のどうぐ](images/04-tool-hissan.png)

*▲ 問題がそのまま筆算の形に。答えのマスは空欄なので、答えは出てきません*

### 1年「くりあがりのあるたし算」→ ブロック／さくらんぼ

![さくらんぼのどうぐ](images/05-tool-sakuranbo.png)

*▲ 「4はあといくつで10になるかな？」。？をタップするとさくらんぼが開きます*

### 1年「とけいクイズ」→ とけい

![とけいのどうぐ](images/06-tool-tokei.png)

*▲ 問題文どおりの針をアナログ時計で描画。「1めもり＝5ふん」の補助つき*

### 5年「百分率」→ わりあい（二重数直線）

![わりあいのどうぐ](images/07-tool-warai.png)

*▲ 「もとにする量を100％とみる」を、割合と百分率の2本の数直線で*

### 6年「速さ・時間・道のり」→ みはじ

![みはじのどうぐ](images/08-tool-mihaji.png)

*▲ 求めたい「？」を指でかくすと、使う式が見える形*

ほかにも、ブロック・位取り表・分数バー・通分バー・面積図・テープ図・アレイ図・単位のはしご・
二重数直線・樹形図・ドットプロット・数直線・図形のスケッチ……と、
**教科書で先生が板書する図が、そのまま出てきます。**

### 授業で効いてくるのは、ここ

- **手が止まった子が、自分で図を開ける。** 「せんせい、わかりません」で待たなくてよくなります
- **答えは出てきません。** 出るのはあくまで「考える手がかり」なので、答えを写して終わりになりません
- どうぐを見て解いた問題は、記録では**「ヒントあり」として分けて**残ります

> **使わせたくない場面では、児童に「今日は電球はなし」と伝えてください。**
> 機能を切るスイッチはあえて用意していません。「必要な子が、必要なときに開ける」ことを優先した設計です。

ペンのボタンを押せば、画面のよこに**手書きメモ**が出ます。筆算はここに書けます。

## 5. まちがえた問題は、自動で「にがて克服ボックス」へ

1回のプレイが終わると、**まちがえた問題だけが一覧で返ってきます。**

![結果画面](images/09-result.png)

*▲ スコア・獲得EXP・最大コンボと、「おさらい（まちがえた問題）」*

さらにこの問題は、次からドリル一覧のいちばん上に **「★ にがて克服ボックス」** として並びます。

![にがて克服ボックス](images/10-mistakes-box.png)

*▲ まちがえた問題が自動でたまっていく。正解できたらボックスから消えます*

**丸つけも、まちがい直しのプリントづくりも、いりません。**
「にがてだけ5分」という指示が、その場で出せるようになります。

> 補足：Qalcは**正解するまで次に進めない**作りなので、単純な正答率は指標になりません。
> 記録では **「1回めで正解できたか（初回正答）」** を主指標にしています。まなびのきろくの「1回めで正解」がそれです。

## 6. クラス全員でやる ──「みんなであそぶ」

ここからが、教室でいちばん盛り上がるところです。
先生（または代表の児童）が1人「リーダー」になって**へや**を作り、ほかの児童が入ります。
サーバーを立てる必要はありません。端末どうしが直接つながります。

### 6-1. へやをつくる

リーダーが **「みんなであそぶ（へやをつくる）」** を押すと、**10けたのルーム番号とQRコード**が出ます。

![へやをつくる](images/11-room-qr.png)

*▲ 番号は4-3-3に区切って表示。QRコードでも、URLの共有でも入れます*

児童は「へやに入る」→ 番号を入力（またはQRを読む）→ ニックネームを入れて申しこみます。
ニックネームは**ひらがな・カタカナ・英数字の8文字まで**。本名を入れさせない運用でお使いください。

### 6-2. 「番号を知っていれば入れる」ではありません

申しこんだ児童は、まず**待機**になります。

![許可を待っている児童の画面](images/12-member-waiting.png)

*▲ 児童側。リーダーが「いれる」を押すまで、参加者の名前も問題もいっさい届きません*

リーダーの画面に「入りたい人」として並び、**リーダーが〈いれる〉を押してはじめて入室**します。

![入室の許可](images/13-approve.png)

*▲ 1人ずつ〈いれる〉／〈ことわる〉。30人まとめて入れる〈ぜんいん いれる〉もあります*

30人学級で30回タップするのは現実的ではないので、**〈うけつけタイム（30秒）〉** も用意されています。
押している30秒間の申しこみは自動で許可され、時間が来ると自動で閉じます（押しなおすまで延長されません）。

> **ルーム番号は約90億通り**（10けた）です。校外の第三者が偶然当てて入ってくることは、まず起きません。
> それでも当てられた場合にそなえて、**リーダーの許可がない端末には、参加者リストも問題文も配信されない**作りになっています。

### 6-3. ボスバトル（協力モード）

**全員の正解が、ボスへの攻撃になります。**

![ボスバトルの開始](images/14-boss-start.png)

*▲ 上にボスのHPとチームHP。正解するたびにダメージが入り、コンボ・フィーバーで威力が上がります*

ボスも反撃してきます。技は全10種類。

| 技の例 | 何が起きるか |
|---|---|
| 問題かくし | 問題文の上にヘドロが落ちて読めなくなる |
| くらやみ | 問題が `??????` になる |
| テンキーシャッフル | 数字キーの並びがバラバラになる |
| かがみ文字 | 問題文が左右反転する |
| のろい | しばらく与えるダメージが半分になる |
| 時限爆弾 | 制限時間内にチーム全体で規定数の正解を出さないと大ダメージ |

![ボスの攻撃](images/15-boss-attack.png)

*▲ 技名のカットインと、かかっている状態（「のろい ダメージ半分」）。HPが3割を切ると「げきおこ」で攻撃が激しくなります*

ここで効いてくるのが **「おうえん」ボタン** です。
正解でたまるゲージを使うと、**仲間にかかった妨害を解除し、チームHPを回復し、ダメージを2倍に**できます。
つまり、**速く解ける子の力が、そのまま仲間を助ける手段になります。**

チームHPが0になっても全滅はしません。「たてなおし」でゲームは続きます。

![ボスバトルの結果](images/16-boss-result.png)

*▲ 倒したボスの数がチームの記録に。アタック／サポート／コンボの3種類のMVPが表彰されます*

**MVPが3種類あるのがポイントです。** 一番速い子だけが目立つ設計にはしていません。

### 6-4. じんとりバトル（チーム対戦モード）

あか・あおの2チームに分かれて、7×7の盤面をぬりあいます。

![じんとりバトルの盤面](images/17-territory-board.png)

*▲ 上が盤面、下が問題。正解するたびに「ねらったマス」がぬられていきます*

- マスをタップして、**自分がねらう場所を自由に決められます**（仲間・敵のねらいもドットで見えます）
- 敵のマスをうばうには+1回、自陣ととなり合っていないマスも+1回 →「どこをねらうか」の作戦が生まれます
- ★マス（3点）とまんなかのマス（5点）が争点
- 正解10回で **スペシャル**（一気にぬる大技）が発動できます
- 盤面の「？マス」はラッキーマス
- **のこり30秒はぬりが2倍**（ラストスパート）。ここで逆転が起きます

![じんとりバトルの結果](images/18-territory-result.png)

*▲ ぬり率とMVP。5種類のMVP（ぬり／こうけん／うばい／スペシャル／コンボ）で表彰されます*

**計算が速い＝勝ち、ではありません。** どこをねらうか、だれが前線を広げるか、いつスペシャルを使うか。
「計算がにがてな子でも、作戦で勝負に加われる」ように作られています。

## 7. 電子黒板に映すとき ──「ていじモード」

教員機を大型提示装置につないだら、画面右上の **🖥ボタン** を押してください。

![ていじモード](images/19-presentation-mode.png)

*▲ 「名前をかくす」は最初からONになっています*

| 項目 | 何が起きるか |
|---|---|
| **大きく表示する** | 文字とボタンが1.5倍に。教室のいちばん後ろの席から読めます |
| **名前をかくす** | 児童名が「た○○」と伏せ字に。**既定でON** |
| **えんしゅつをへらす** | 紙ふぶき・画面のゆれ・端末のふるえを止めます |
| **ぜんがめんにする** | メニューバーを消して画面いっぱいに映します |

> **「えんしゅつをへらす」は、感覚過敏のある児童の端末でも使ってください。**
> 紙ふぶきや振動がつらい児童がいます。端末側の設定（「視差効果を減らす」）でも同じように止まります。

> **「名前をかくす」を切るときは、画面が廊下や参観の保護者から見えていないか確かめてください。**
> 既定でONにしてあるのは、大型提示装置がそういう場所に置かれることが多いためです。

## 8. 授業のどこで使うか（5つの型）

実際に組みこみやすいのは、このあたりです。

### ① 帯タイムの5分（毎日）
スコアアタック3分＋まちがい直し2分。学年の該当ドリルを選ぶだけ。**丸つけが発生しません。**

### ② 単元のはじめ（前学年の復習）
1つ下の学年のドリルを選んで5分。**その場でつまずきの分布が見えます**（まなびのきろくの「もういちどやってみよう」）。

### ③ 単元末（力だめし）
タイムアタック（全20問）。「何分で終わったか」が出るので、児童自身が前回と比べられます。

### ④ 早く終わった子の待ち時間
「終わった人はQalcの★にがて克服ボックス」。指示が1行で済みます。

### ⑤ 学期末・行事のあと・雨の日（学級レク）
**ボスバトル or じんとりバトル。** 3分で1試合。準備は「へやをつくる」の1タップです。
授業参観や学級開きの「一体感づくり」にも向いています。

## 9. 先生が気になるところ

導入前に情報担当の先生から必ず聞かれる部分を、先にまとめておきます。

### 個人情報について

- **アカウント登録はありません。** 氏名・メールアドレス・生年月日はあつかいません
- **学習の記録・成績・コイン・きせかえは、すべてその端末の中（localStorage）に保存され、外部に送信されません**
- **広告もアクセス解析のタグも入っていません**
- 「みんなであそぶ」で他の端末に伝わるのは、**児童が自分で入力したニックネーム（8文字まで）とスコア・コンボだけ**です

### 校内フィルタリングで許可が必要なホスト

| ホスト | 用途 | ブロックされると |
|---|---|---|
| `gigayama.github.io` | アプリ本体の配信 | アプリが開けない |
| `0.peerjs.com` | みんなであそぶ（へやの番号のやりとり） | **みんなであそぶだけ**が使えない |
| `stun.l.google.com` / `eu-0.turn.peerjs.com` / `us-0.turn.peerjs.com` | 端末どうしのつなぎ役 | 環境によってつながらない |

> **ひとりで遊ぶだけなら、`gigayama.github.io` が通っていれば動きます。**
> 逆に、「みんなであそぶは使わせない」運用にしたい場合は、**`0.peerjs.com` をブロックすれば1人用だけに限定できます。**

### オフラインでも動きます

ホーム画面に追加（インストール）しておけば、**インターネットにつながっていなくても1人用モードは使えます。**
フォントもプログラムも全部同梱してあるので、外部CDNへの通信は発生しません。

### 共用端末で使うときの注意

1人1台でない場合、**学習の記録はその端末に残ります。**
名前は保存していないので個人の特定はできませんが、前に使った児童の成績は見えます。その前提でお使いください。

### iPadは「ホーム画面に追加」を強くおすすめします

Safariには**7日間使わないと保存データを消す仕組み**があります。
ホーム画面から使っていない場合、コインやレベルが消えてしまうことがあります。

### 音について

**はじめは音が出ない設定になっています**（教室で30台が一斉に鳴らないように）。
出したいときは画面右上のスピーカーボタンで切りかえます。

## 11. おまけ：続ける仕掛けと、コースの自作

### コインで「きせかえ」

正解やミッション達成でたまるコインで、アバターやテーマを買えます。全部で471種類。

![きせかえショップ](images/20-shop.png)

*▲ 動物のベース・ぼうし・かお・もちもの・はいけい・エフェクト・しょうごう・テーマ13種*

「今日もやろう」を作るための仕掛けです。ただし、
**マスターしたドリルを周回したり、同じドリルを同じ日に連続でやったりすると、もらえるEXP・コインは減っていきます。**
「同じ問題を回してコインだけ稼ぐ」ができないようにして、次のドリルへ進むように寄せてあります。
（にがて克服ボックスと、まちがいが増えたドリルの復習は、いつでも満額です）

### 問題を自分で作る・配る

「コース管理」から、オリジナルの問題コースを作れます。

![コース管理](images/21-course-manager.png)

*▲ 各コースの共有ボタンから共有コードを発行。「受信/AI」からは他の先生のコースを取りこめます*

- **共有コード**で、作ったコースを他の先生・他の学級に配れます
- **ChatGPTやClaudeに問題を作らせてCSVで取りこむ**こともできます（学校独自の文章題や、地域素材を使った問題を作りたいときに）

## 12. Qalcを使うと、何が変わるか

最後に、実際に何が変わるのかを整理します。

**先生にとって**

- 印刷・配付・回収・丸つけが**まるごと消えます**
- 「まちがい直し」の教材づくりが不要になります（にがて克服ボックスが自動で作ります）
- つまずいている問題が**その日のうちに数字で見えます**（1回めで正解した割合／もういちどやってみよう）
- アカウント発行・名簿登録・保護者同意の手続きが**発生しません**

**児童にとって**

- **手が止まったときに、自分で図を開ける**（＝待たなくていい）
- まちがえた問題が**自動で自分専用の練習セットになる**
- 「計算が速い子」だけでなく、**支える子・作戦を立てる子にもMVPがある**
- 続けた日数・集中した時間・伸びが、**自分の画面で見える**

計算練習は、どうしても「作業」になりがちです。
Qalcがやろうとしているのは、その5分を**「今日もやりたい」に変えること**と、
**つまずいた子が自分の力で一歩進めるようにすること**の2つです。
