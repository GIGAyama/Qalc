# Qalc

**小学生向け計算ゲーム学習アプリ** - みんなで楽しく算数を学ぼう！

> React製のブラウザ計算ゲーム。1〜6年生の算数をカバーし、P2Pマルチプレイ・きせかえ・デイリーミッションなどゲーミフィケーション要素を搭載。

## デモ

https://gigayama.github.io/Qalc/

## 特徴

### 5つのゲームモード

| モード | 説明 |
|--------|------|
| **スコアアタック** | 制限時間内にハイスコアを目指す（1〜10分） |
| **タイムアタック** | 全20問をできるだけ早くクリア |
| **サドンデス** | 1問でもまちがえたら終了 |
| **ボスバトル** | みんなであそぶ専用の協力モード。全員の正解でボスを攻撃し、制限時間内に何体たおせるかに挑戦 |
| **じんとりバトル** | みんなであそぶ専用のチーム対戦モード。あか/あおに分かれて7×7の盤面をぬりあう |

- 正解した瞬間に自動で次の問題へ進むスピーディーな操作感
- コンボシステム（5コンボ以上でフィーバーモード発動）
- 手書きメモキャンバス付き

### かんがえるどうぐ（学習補助ツール）

問題の内容（数の大きさ・演算の種類）に合わせて、使えるどうぐを自動判定。ゲーム中に電球ボタンからワンタップで開けます。

| どうぐ | 内容 | 出る条件の例 |
|--------|------|--------------|
| ブロック | タップして数えられる算数ブロック（10のまとまり表示） | 20までのたし算・ひき算、低学年の文章題 |
| さくらんぼ | くり上がり・くり下がりの分解をタップで確かめる | 8+5 のようなくり上がり、13-9 のようなくり下がり |
| ひっ算 | 問題を筆算の形で表示（答えのマスは空欄） | 2けた以上のたし算・ひき算・かけ算・わり算 |
| くらい | 位取り表に数を並べて表示（小数対応） | 100以上の数や小数をふくむ問題 |
| とけい | 問題文どおりの時刻・針の動きをアナログ時計で描画（動いた分は弧で表示） | とけいクイズ |
| ながさ | テープ図で「つなぐ・きりとる」を長さに比例した図で表示 | ながさのけいさん |
| かさ | めもり付きのますに水の量を描画（のむ分は色分け） | かさのけいさん |
| えん | 半径と直径の関係を円の図で表示 | 円と球 |
| アレイ | かけ算・わり算・あまりを「◯こずつ◯れつ」の点の並びで表示 | 九九、九九あなうめ、わり算、あまり、かけ算・わり算の文章題 |
| ぶんすう | 分数バー（同分母・異分母）と「◯つに分けた1つ分」の円図 | 2〜5年の分数コース |
| みはじ | 道のり・速さ・時間の関係図（求めるものを？で表示） | 速さ・時間・道のり |
| すうちょくせん | 四捨五入する数を数直線上に表示（まんなかの値つき） | がい数（四捨五入） |
| ずけい | 長方形・三角形・平行四辺形・直方体・角柱・円柱などのスケッチと公式 | 面積・体積のけいさん |
| ならび | 「まえから◯ばんめ」を人の並びの図で表示 | ことば（じゅんじょ） |
| じゅんばん | さきに計算する部分をハイライト | 計算のきまり、四則混合 |

このほか、あわせて10（◯+?=10）では10フレーム（10のへや）が出ます。

### リアルタイムマルチプレイ

PeerJS（WebRTC）によるP2P通信で、サーバー不要のマルチプレイを実現。

- **へやをつくる** - 6桁のルーム番号を発行、QRコード・URL共有に対応
- **へやに入る** - ルーム番号を入力して参加
- リアルタイムスコア同期 & ライブランキング表示
- リーダー（ホスト）もメンバーと一緒にゲームをプレイ可能

#### 協力モード「ボスバトル」

個性ゆたかな4体のボス（スライムキング・プルン、カウントドラゴン・ゴロン、まじょねこ・ニャルル、メカボス・カリキュロン）と連戦する協力レイド。

- 全員の正解がボスへのダメージに。コンボ・フィーバーでダメージアップ
- ボスも反撃してくる（問題かくし・くらやみ・テンキーシャッフル・入力こおり・チームHP攻撃）
- 正解でたまる「おうえん」ゲージで仲間のデバフ解除＆チームHP回復＆ダメージ2倍
- たおすたびに次のより強いボスが登場。時間内の撃破数がチームの記録に
- 結果発表では与ダメージ・おうえん回数を可視化し、アタック/サポート/コンボMVPを表彰

#### チーム対戦モード「じんとりバトル」

あか/あおの2チームに分かれて7×7の盤面をぬりあう対戦モード。問題を解く画面と盤面を同時に見ながら、「どこをねらうか」の作戦がカギ。

- 正解するたびに、ねらったマスへ1ぬり（フィーバー中は2ぬり）。必要ぬり数がたまるとチームの色に
- マスをタップして自由にねらいを変更。仲間・敵のねらいもドットでリアルタイム表示
- 敵のマスをうばうには+1、自陣にとなり合っていないマスも+1コスト → 前線を広げる陣形戦略が生まれる
- ★マス（2pt）とまんなかのマス（3pt）は高コストだが高得点。うばえない本陣（🏠）から陣地を拡大
- ロビーでチーム分けを自由に編成（参加時は人数の少ない側へ自動割当）
- 全マスがうまるか時間切れで終了。合計ポイントの多いチームが勝利し、ぬり/こうけん/コンボMVPを表彰

### 50以上の計算コース（小学1〜6年）

学年別にプリセットされた計算問題コース群。

| 学年 | 主な内容 |
|------|----------|
| 1年 | あわせて10、くりあがり、ひきざん、とけい |
| 2年 | 九九（各段・穴埋め）、2けたの計算、分数 |
| 3年 | わり算、あまり、3〜4けた、小数、単位変換 |
| 4年 | 大きな数（億・兆）、がい数、面積、角度 |
| 5年 | 割合(%)、公倍数・公約数、3.14、体積 |
| 6年 | 分数かけわり、速さ、比、場合の数、データ |

#### コースのカスタマイズ

- オリジナル問題の作成・編集
- 共有コードで他のユーザーとコースを共有
- AI（ChatGPT / Claude）で問題を自動生成し、CSVインポート
- **にがて克服ボックス** - まちがえた問題を自動収集し重点練習

### ゲーミフィケーション

- **レベルシステム** - EXPを獲得してランクアップ（🌱かけだし → 👑計算マスター → 🌌計算神）。レベルアップ時はコインボーナス＆スター紙吹雪でお祝い
- **れんぞく学習ストリーク** - 毎日続けるとホーム画面に🔥連続日数を表示
- **デイリーミッション** - 毎日3つのミッションをクリアしてコインを獲得
- **きせかえショップ** - コインでアバターパーツ（76種以上）やテーマ（13種）を購入
- **がんばりグラフ** - 直近7日間の学習状況を可視化

### アクセシビリティ

- 漢字にふりがな（ruby）対応
- 13種のカラーテーマ（ダーク・さくら・オーシャン・サイバーなど）
- 効果音 & BGM（Web Audio APIによる合成音）、ON/OFF切替
- モバイルファースト設計（タッチ操作・バイブレーション対応）
