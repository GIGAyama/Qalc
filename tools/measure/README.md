# 実測ツール（GIGA Standard v5 §7）

**読むだけでは分からないことを測るためのもの。**

静的な検査（`npm run check`）は「ソースに何が書いてあるか」しか見られない。
v5 で Qalc を測り直したとき、静的な検査は44項目すべて合格していたのに、
実ブラウザではコントラスト110件・タップ領域159件が基準未満だった。
その差を埋めるのがこのツールである。

## 使いかた

```bash
npm i --no-save playwright     # 1回だけ。package.json には入れない（下記）
npm run build
npm run measure
```

落ちたものがあれば終了コード 1 で止まる。

個別に走らせることもできる。

```bash
node tools/measure/serve.mjs dist 4180   # dist を /Qalc/ の下に配る（別の端末で）
node tools/measure/routes.mjs            # 画面ごとの表示（W/H で画面幅を変える）
node tools/measure/offline.mjs           # 圏外ページ
node tools/measure/icons.mjs             # アイコンを画素で数える
node tools/measure/pwa.mjs               # 登録・更新・オフライン・他アプリのキャッシュ
```

## なぜ playwright を package.json に入れていないか

`npm ci` のたびにブラウザ本体（数百MB）を取りにいくことになり、
CI が遅くなるうえ、校内から使うわけでもないものを全員に配ることになる。
**リリース前に人が走らせるもの**として、必要なときだけ入れる形にしてある。

`CHROME_PATH` を指定すれば、手もとの Chrome/Chromium をそのまま使える。

## 何を測っているか

| ファイル | 測るもの |
|---|---|
| `routes.mjs` | コントラスト・タップ領域44px・横スクロール・ふりがな・CSP違反・JSエラー |
| `offline.mjs` | 圏外ページの同上と、「もういちど ためす」が本当に戻るか |
| `icons.mjs` | apple-touch-icon の透明・maskable のセーフゾーン外の中身 |
| `pwa.mjs` | 登録・初回リロード・押すまで切りかわらない・他アプリのキャッシュ・圏外起動 |

## 測りかたで踏んだ落とし穴（消さないこと）

ここに書いてあることは、実際に誤報を出して気づいたものである。

1. **色は 1px 実際に塗って読む。** Tailwind v4 の `oklch()` は数字だけ拾うと
   まったく違う色として読める。`ctx.fillStyle` に入れて読み返しても `oklch` のまま返る。
2. **`framenavigated` を数えない。** `history.pushState()` でも飛ぶので、
   端末の「戻る」でモーダルを閉じる作りのアプリでは必ず2回以上になる。
   数えるべきは「文書が何回読みこまれたか」。
3. **アニメーションが終わるまで待つ。** 600ms では足りず、まだ出ていない要素を
   数え落とした。2,200ms で安定した。
4. **総当たりで押して回らない。** モーダルが開いたままの画面と本来の画面を
   「同じ画面」と判定して、11件のタップ不足を 0件に取りこぼした。
   画面ごとにまっさらから入り直すこと。
5. **判定の前にコメントを落とす。** 「以前は `<script>` で動かしていた」という
   説明書きに反応して、直したはずのものを未修正と誤判定した。
6. **版の文字列を決め打ちしない。** `APP_VERSION = 'v4'` と書いていたら、
   リリースで v5 に上がった瞬間に置きかえが空振りし、
   「更新が起きない」を「更新が起きなかった」と取りちがえた。

## 測れないもの

- 本番（`gigayama.github.io`）での挙動。作業環境から到達できない
- `wss://0.peerjs.com` を使う「みんなであそぶ」の本編。入口までは測れる
- 記録が無いと出ない画面（きろく）
